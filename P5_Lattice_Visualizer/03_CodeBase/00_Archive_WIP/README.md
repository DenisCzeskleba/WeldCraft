# Archived Lattice Visualizer Experiments

This directory preserves unfinished PyVista experiments from the pre-WeldCraft
development folder:

- `visualize_lattice_hotreload.py` watches the YAML configuration and reloads
  the scene.
- `visualize_lattice_gui.py` adds experimental PyVista controls on top of the
  reload behavior.

These scripts are unsupported, are not connected to the WeldCraft launcher,
and must not be included in standalone releases. The production entry point is
`P5_Lattice_Visualizer/visualize_lattice.py`.
